# Configuration

The configuration of the ARLAS Exploration Stack, when deployed on kubernetes, is done in the values.yaml file of the corresponding chart. One "umbrella" chart per type of deployment is provided:
- [simple](k8/charts/simple/README.md)
- [iam](k8/charts/arlas-iam/README.md)
- [aias](/k8s/charts/aias/README.md)
